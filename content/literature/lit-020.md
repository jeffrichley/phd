## What it establishes

MemGPT — the system that became Letta — is the reference design for an agent that manages
its own memory. It splits memory into a main context (the prompt: fixed system
instructions, a read/write working-context block, and a message queue) and external
context (recall storage holding the full message history, archival storage holding
arbitrary text), and lets the model itself move data between tiers by emitting function
calls: "memory edits and retrieval are entirely self-directed." When the context fills, a
memory-pressure warning prompts the model to consolidate what matters; evicted messages
are replaced in-context by a recursive summary but kept in storage. The payoff is
measured: on a deep-memory-retrieval task over multi-session chat, GPT-4 Turbo with
MemGPT answers at 93.4 percent accuracy against 35.3 percent for the same model without
it; on document question answering its accuracy stays flat as documents grow while
fixed-context baselines degrade; and it is the only approach that consistently completes
a nested key–value lookup beyond two nesting levels, by chaining its own retrieval calls
— multi-hop retrieval, self-directed.

## What to pull

- The production-practice half of the thread-d claim: paired with Voyager, the evidence
  that structured, self-curated external memory is standard architecture in deployed
  agent systems, while its value for motor skills remains untested (RQ2).
- The mechanism vocabulary: tiered memory, pressure-triggered consolidation, and paged
  self-directed retrieval are the text-domain analogs of a mission-time skill store's
  admit, evict, and retrieve policies.
- The nested key–value result as the text analog of composition — chaining retrievals to
  reach an answer no single lookup provides.

## Where it stops

MemGPT's memory is conversational and document state: what it pages in and out are
sentences — facts about a user, past messages, Wikipedia passages. Nothing in any tier is
a skill; the system never acts on a world beyond emitting text, so there is no motor
control, no physical dynamics, no robot, and no simulator. Nothing certifies the store
either: working context is free text the model chose to write, summaries are lossy, and
evaluation is question-answering accuracy under an LLM judge — no measure that a
remembered item confers a competence. And because the backbone is frozen and nothing is
ever trained, the comparison the dissertation needs — structured memory against
weight-update continual learning — cannot even be posed in this system. The dissertation
asks whether this architecture's virtues survive when the stored items are dynamical
controllers under fluid coupling, where a retrieved memory must not just read well but
swim.
