## What it establishes

GOLLUM demonstrates continual locomotion learning on a physical hexapod: walking, slope
climbing, and bouncing acquired within roughly one hour without human intervention. Its
architecture grows a new neural column per new condition (neurogenesis triggered by
value/observation prediction mismatch), where each column is a ring network of central
pattern generators encoding one skill. Two learning pathways operate together: primary
learning trains the active column's own skill, masked so other columns are untouched
(forgetting handled structurally), and supplementary learning updates inter-column
connections that "combine previous learned skills to facilitate the learning process of
new skills." It also catalogues why off-the-shelf continual learning fails on locomotion:
elastic weight consolidation drops performance by around 20 percent, and replay is costly
and degrading.

## What to pull

- The head-on engagement RQ2 requires: GOLLUM's supplementary learning is a
  compositional-scaffold-at-acquisition mechanism: composing prior skills to bootstrap a
  new one is exactly the dissertation's move, so GOLLUM is the closest prior to the
  mechanism, not merely a baseline.
- The baseline it defines: GOLLUM-style opaque parameter transfer is the warm-start
  comparator the forward-transfer headline must beat.
- Its evidence that naive continual learning fails on locomotion, motivation for a
  non-gradient alternative.
- The shared substrate observation: GOLLUM's skills are literally CPG networks,
  reinforcing that CPG parameter banks are the incumbent skill representation an external
  memory would store.

## Where it stops

The composition happens in weights that cannot be inspected: supplementary connections are
learned combination ratios between columns, growth is triggered by opaque prediction-error
signals, and there is no queryable record of what a skill is or why it was reused. The
robot is a legged terrestrial hexapod, so the fluid coupling that makes gait modes
categorical for a swimmer is absent. The dissertation asks whether the same
combine-frozen-skills idea, routed through an inspectable structured memory instead of
opaque inter-column connections, buys measured forward transfer that this opaque scaffold
cannot.
