## What it establishes

Each expert is a reinforcement-learning policy (PPO with motion imitation and domain
randomisation) tracking one reference motion (a gait or a jump) trained independently.
The composer policy drives the robot from its current state to a sampled target state of
the next skill using shrinking tolerance boundaries and an energy penalty, and because it
depends only on the target state and not on any expert's internals, a new expert composes
for free with no retraining of anything existing. Across 72 transition pairs it achieves
99.99 percent transition success in simulation and 97.22 percent on hardware, preserving
each skill's original motion quality.

## What to pull

- The partial precedent it sets: "locomotion skill repertoire, expandable without
  retraining" is already partly solved, which sharpens what the dissertation must add on
  top of it rather than claim outright (RQ2 positioning).
- The transition mechanism itself: how retrieved skills physically hand off to one another
  is a real problem for a swimmer, and this paper's smooth state-to-state transition
  design is the direct reference for chaining composed skills.

## Where it stops

The system has no external memory queried by situation: which experts to sequence is given
to it, so the selection problem (deciding from an inspectable record which stored skills
apply and composing them to acquire a new one) never arises. There is no
continual-learning framing at all: no task sequence, no forgetting metric, no
weight-update baseline, and no forward-transfer measurement. The robot is a terrestrial
quadruped moving between pairwise transitions rather than novel long-horizon missions.
The dissertation adds the retrieved, inspectable memory with situation-conditioned
selection, the controlled comparison against weight-update continual learning, and the
snake-form underwater embodiment where fluid coupling makes the skills categorical.
