What the ledger records

One Markdown file per run, committed to the repository and published on the next build — there is no way to add a run from this page, by design. The frontmatter below is the complete schema the ledger reads; the body becomes the expanded detail.

---
id: exp-006
date: 2026-09-08
rq: rq1
hypothesis: H1.1
env: 
method: 
seeds: 5
status: running        # queued | running | done | failed | superseded
commit: 
metrics:
  success_rate: [mean, std]
  forgetting: [mean, std]
artifacts:
  - label: training curves
    href: 
---

## Reading
What this run says about the hypothesis, written before the next run starts.
Immutability Never edit a reported run. Supersede it with a new id and set the old one's status to superseded. The trail is what makes the ledger worth having.
Seeds The seeds field is sortable so you can find the under-powered runs before a committee member does.
