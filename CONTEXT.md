# phd (progress site) — domain glossary

Ubiquitous language for the advisor-facing progress site. The program-level terms
*progress site* and *lab note* are canonical in phd-lab `CONTEXT.md` § Advisor-facing
site; this glossary adds only site-local terms. No implementation detail here.

| Term | Meaning |
|---|---|
| **Progress site** | See phd-lab CONTEXT.md. Short form: an advisor-facing *presentation* of the dissertation plan plus a running record — not the formal ODU proposal document. |
| **Lab note** | See phd-lab CONTEXT.md. One dated, advisor-readable entry; a review-gated retelling of working-notebook material, never a raw pipe. |
| **Slot inventory** | The fixed set of named content slots each of the four templates (landing, content page, feed index, feed entry) must expose. The contract between content and design: neither side changes it without saying so. |
| **Open-decision callout** | A visually distinct box naming a question the program has deliberately not answered yet. Shows rigor and hands the advisor an agenda item. Used for degree-relevant open ends only. |
| **Locked source** | A phd-lab document or issue marked locked that a page is drafted from and cites. Pages restate locked sources for a committee audience; they never contradict them. |
